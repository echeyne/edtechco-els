\section{System Architecture}
\label{sec:system-architecture}

\begin{figure*}
  \centering
  \includegraphics[width=\textwidth]{figures/fig_architecture.pdf}
  \caption{Pipeline architecture. Documents flow through eight serverless
  stages; solid arrows carry data, dashed arrows are model calls, and dotted
  arrows show that stages exchange JSON through S3 rather than direct payloads.
  Detection and parsing are batched through a prepare $\rightarrow$ Step
  Functions \texttt{Map} $\rightarrow$ merge pattern (at most three concurrent
  workers) so that large documents do not exhaust the Lambda timeout; detection
  batches by text-block chunk and parsing by domain, which keeps related
  elements together. Detection is two-pass: a depth-map pass infers the
  document's nesting hierarchy before elements are classified against it.
  \textbf{Note that the evaluation suites exercise the direct path rather than
  this batched one, and the two are known to diverge}
  (\S\ref{sec:discussion-limitations}). Regenerate with
  \texttt{python paper/analysis/make\_architecture\_figure.py}.}
  \label{fig:architecture}
\end{figure*}

Figure~\ref{fig:explorer} shows the end of that pipeline as a user meets it:
extracted standards resolved into the canonical schema and served through the
Standards Explorer, where the per-element verification workflow of
\S\ref{sec:method-confidence} is carried out.

\begin{figure*}[t]
  \centering
  \includegraphics[width=\textwidth]{figures/colorado_els.png}
  \caption{The Standards Explorer, showing extracted Colorado standards resolved
  into the canonical schema of \S\ref{sec:schema}. The hierarchy is navigable to
  its full depth --- domain \texttt{AL} (Approaches to Learning), strand
  \texttt{AL.1}, and the indicators \texttt{AL.1.1}--\texttt{AL.1.7} beneath it
  --- with each row carrying the age range in months and the page of the source
  PDF it was extracted from, so any record can be checked against the document
  that produced it. The \emph{Status} column is the per-element human
  verification state described in \S\ref{sec:method-confidence}: every row here
  reads \texttt{Unverified}, which is the system's default and is
  \textbf{independent of the model's confidence score}. Confidence gates nothing
  and never sets this field; verification is a separate editorial action
  recorded per element. Colorado realizes three levels rather than four, which
  is why indicators attach directly to strands here.}
  \label{fig:explorer}
\end{figure*}
